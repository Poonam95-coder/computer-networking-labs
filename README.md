# computer-networking-labs
Basic network simulations using cisco packet tracer
## Included Labs
- Star Topology: Basic network topology setup  
- Router Configuration: Basic routing between networks  
- FTP Server Setup: Client-server communication  
- EIGRP Routing: Dynamic routing protocol configuration  
- RIP Routing: Basic dynamic routing using RIP protocol  

## Concepts Practiced
- IP addressing  
- Static and Dynamic Routing (RIP, EIGRP)  
- Client-server model  
- Peer-to-peer connectivity  

## Tool Used
- Cisco Packet Tracer
